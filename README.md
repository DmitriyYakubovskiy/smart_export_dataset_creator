# Анамнез — сбор текстов из Word

Небольшое приложение для ручного сбора анамнезов из DOCX. Один аккаунт без регистрации; любое число документов и анамнезов. FastAPI, SQLite, обычный браузер. Внешние сервисы и модели не используются.

## Быстрый запуск на сервере

Нужны Docker с Compose v2 и Python 3 для однократного создания настроек. Распакуйте архив и откройте каталог anamnesis:

```bash
python3 setup.py
docker compose up -d --build
```

setup.py показывает логин и случайный пароль, записывает их в .env и не перезаписывает существующую конфигурацию. Пароль можно заменить в .env (не менее 12 символов); после изменения выполните `docker compose up -d --force-recreate`. Смена пароля после пересоздания контейнера автоматически делает старые сессии недействительными.

По умолчанию приложение доступно только самому серверу по http://127.0.0.1:8080. Для быстрого доступа со своего компьютера используйте SSH-туннель (в отдельном терминале):

```bash
ssh -L 8080:127.0.0.1:8080 user@SERVER_IP
```

Откройте на компьютере http://localhost:8080 и введите выданные данные. В закрытой локальной сети можно установить BIND_ADDRESS=0.0.0.0 в .env, пересоздать контейнер и открыть http://SERVER_IP:8080. Для доступа через интернет используйте HTTPS через существующий reverse proxy и COOKIE_SECURE=true; оставьте привязку порта к 127.0.0.1. Не включайте COOKIE_SECURE=true при доступе по обычному HTTP.

## Работа

1. Войти. Регистрации и создания дополнительных пользователей нет.
2. Нажать «Загрузить документы» и выбрать один или несколько файлов .docx (до 30 МБ каждый).
3. Выбрать документ слева. Справа откроются его текст и таблицы. Объединённые горизонтально ячейки не дублируют текст.
4. «Найти анамнез» последовательно показывает упоминания этого слова, включая «аллергоанамнез».
5. Выделить нужный фрагмент и нажать «Взять выделенное» либо скопировать текст из Word в поле слева. Можно повторять перенос выделений: они добавляются к тексту формы.
6. При необходимости задать название и нажать «Сохранить анамнез». Связь с документом создаётся автоматически. Добавлять можно любое число записей.
7. Записи можно редактировать и удалять с подтверждением. Пометка «Просмотрен» помогает отслеживать работу и не запрещает дальнейшее редактирование.
8. Экспорт CSV/JSON выгружает все сохранённые анамнезы: ID записи, ID документа, исходное имя, название, текст, даты создания и изменения (Unix timestamp, UTC). CSV — UTF-8 BOM, разделитель «;». Формулоподобный текст экранируется апострофом для безопасного открытия в Excel; JSON хранит исходный текст.

У одного файла может быть несколько записей, одинаковые имена разных файлов различаются по ID. Повторная загрузка создаёт отдельный документ. Черновик существует только в открытой вкладке: нажимайте «Сохранить». При уходе с несохранённым текстом приложение запрашивает подтверждение.

## Где данные

В ./data/app.sqlite3 — документы, анамнезы, сессии. В ./data/files — оригиналы DOCX и подготовленные представления. Папка подключена к контейнеру, перезапуск/пересборка её не удаляет. Вход защищает просмотр, скачивание, экспорт и изменение данных. Сессия действует 12 часов. После 10 неверных входов с одного адреса действует ограничение на 10 минут; за reverse proxy адресом может быть адрес прокси.

Для согласованной резервной копии остановите приложение, скопируйте всю data и .env, затем снова запустите:

```bash
docker compose stop
# Скопируйте data и .env в защищённое место
docker compose start
```

Архив программы не содержит ваших медицинских документов. Пример 1.docx загрузите после входа. Все документы остаются на вашем сервере.

## Ограничения просмотра

Поддерживается DOCX, не старый DOC и не PDF. Просмотр сохраняет текст и таблицы в порядке документа, но не точную вёрстку Word: изображения, колонтитулы, разрывы страниц и часть форматирования не показываются. «Скачать Word» открывает возможность работы с оригиналом. Автоматическое извлечение анамнеза не выполняется: текст выбирает человек. Один общий аккаунт не позволяет различать авторов изменений; параллельное редактирование одной записи сохраняет последнюю версию.

## Проверки

```bash
python -m pip install -r requirements.txt pytest httpx
python -m pytest -q
```

Тесты изолированы от рабочей базы: используют временную папку. Проверяют вход, недоступность файлов без сессии, загрузку, связь документа и записей, изменение/удаление/экспорт, проверку запросов, отсутствие повторов объединённых ячеек и экранирование HTML. Результаты подготовки см. TEST_RESULTS.txt. Сборка Docker требует скачивания базового образа и зависимостей при первом запуске.
